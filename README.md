# Minotaur Arcade

Экспериментальный SMAPI-мод для Stardew Valley 1.6 с двумя игровыми автоматами, видом от первого лица (raycasting), минотавром и лобби внутри одной кооперативной фермы.

**Статус:** исходники подготовлены, совместимость в реальной игре не подтверждена. Готовый ZIP публикуется автоматически в [Releases](../../releases/tag/auto-build) только после успешной компиляции.

В целях первоначальной публикации исходный комплект проекта размещён в `source/MinotaurArcade_payload.tar.xz` и разворачивается во время GitHub Actions. Сайт находится внутри пакета (`site/`); дальнейшие изменения можно переносить в обычные исходные файлы.
